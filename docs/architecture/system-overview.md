# System Overview

## Purpose

Liga MX Draft Generator is a client-side web application used to generate a randomized draft order and assign unique Liga MX teams to players.

## Components

### User Interface

Allows users to:

- Enter player names
- Generate draft order
- View assigned teams
- Reset draft session

### Draft Engine

Responsible for:

- Player validation
- Randomization
- Team assignment
- Duplicate prevention

## Data Flow

1. User enters player names
2. Validation is executed
3. Draft order is randomized
4. Teams are assigned
5. Results are displayed

## Deployment

Current deployment model:

- Frontend only
- Static hosting
- No backend services
- No database
